# Tareas — hero-name-image-hover

**Objetivo:** implementar en el `h1` del Hero de «Héctor Reyes» una interacción de hover que sustituye cada letra por una de dos variantes aleatorias de tile de color, y devuelve la letra con una demora breve al salir.

**Problema y motivo:** hoy el nombre del Hero es texto plano. El usuario pidió replicar el efecto descrito en el título de OpenAI sin API de imágenes; los tiles deben quedar preparados para reemplazarse por imágenes después.

**Alcance:** `Hero.astro`, un inicializador en `src/lib/core/`, estilos de `hero.css`, pruebas deterministas y evidencia visual/accessibility/responsive. Solo el título del Hero.

**Restricciones y decisiones:**
- Conservar exactamente un `h1` y el texto accesible/copiable «Héctor Reyes», incluido el espacio real entre las palabras.
- Once letras, dos variantes por letra; sorteo independiente en cada hover; nunca mostrar dos variantes a la vez.
- Reutilizar tokens existentes; restaurar tras 180 ms y usar la transición existente de 150 ms.
- Efecto únicamente con mouse y hover fino; estático en touch y `prefers-reduced-motion: reduce`.
- Sin llamadas API, nuevas dependencias, cambios a otros encabezados ni generación de imágenes.
- SDD en OpenSpec, ejecución automática. Entrega seleccionada: PRs encadenados con `feature-branch-chain`; el usuario aceptó `size:exception` solo para PR2 (Slice B, ~682 líneas authored), no para otras slices. No crear commits, pushear ni abrir PRs sin autorización explícita adicional.
- Usar asignaciones globales de modelos SDD; no crear overrides de modelo en el proyecto.
